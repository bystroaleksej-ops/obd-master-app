# OBD Master Pro (Android 15 / API 35)

Современное нативное Android-приложение для полной диагностики автомобиля и работы с адаптерами **ELM327** (Bluetooth и Wi-Fi).

Проект полностью оптимизирован под **Android 15 (Target SDK 35)** с соблюдением требований безопасности, фоновых служб (`FOREGROUND_SERVICE_CONNECTED_DEVICE`) и разрешений Bluetooth (`BLUETOOTH_SCAN`, `BLUETOOTH_CONNECT`).

> [!NOTE]
> В приложении **полностью исключены** запись поездок, треков и фоновых баз логов по требованию заказчика. Фокус сделан исключительно на мгновенной диагностике, чтении параметров и управлении ЭБУ.

---

## Возможности приложения

### 1. Цифровая приборная панель (Dashboard)
* **Hero-приборы**: Скорость автомобиля (`01 0D`) и Обороты двигателя (`01 0C`).
* **Мониторинг датчиков в реальном времени**:
  * Температура охлаждающей жидкости (`01 05`)
  * Расчетная нагрузка на двигатель (`01 04`)
  * Положение дроссельной заслонки (`01 11`)
  * Температура воздуха на впуске (`01 0F`)
  * Массовый расход воздуха MAF (`01 10`)
  * Давление во впускном коллекторе MAP (`01 0B`)
  * Угол опережения зажигания (`01 0E`)
  * Краткосрочная и долгосрочная коррекции топлива STFT / LTFT (`01 06`, `01 07`)
  * Уровень топлива в баке (`01 2F`)
  * Напряжение бортовой сети и ЭБУ (`01 42` и `AT RV`)
  * Температура моторного масла (`01 5C`)
  * Мгновенный расход топлива (`01 5E`)
  * Время работы двигателя (`01 1F`)
  * Атмосферное давление (`01 33`)

### 2. Диагностический центр (DTC Trouble Codes)
* **Считывание всех типов ошибок**:
  * `Mode 03` — Подтвержденные коды (Stored DTCs).
  * `Mode 07` — Ожидающие подтверждения коды (Pending DTCs).
  * `Mode 0A` — Постоянные коды (Permanent DTCs).
* **Встроенный декодер SAE J2012**: преобразование сырых hex-байтов в стандартный формат `Pxxxx`, `Cxxxx`, `Bxxxx`, `Uxxxx`.
* **База описаний на русском языке**: подробная расшифровка каждого кода неисправности.
* **Сброс кодов ошибок (Mode 04)**: стирание ошибок из памяти ЭБУ и погашение индикатора *Check Engine (MIL)* с подтверждением через диалоговое окно.

### 3. Осциллограф датчиков (Live Charts)
* Высокоскоростной рендеринг графика на `Canvas` без задержек интерфейса.
* Возможность переключения между любыми поддерживаемыми датчиками.
* Отображение текущего значения, единиц измерения, категории и границ измерений.

### 4. Терминал адаптера и информация об автомобиле (Terminal & Mode 09)
* **Паспортные данные авто (Mode 09)**:
  * VIN-номер автомобиля (с преобразованием ASCII байтов в строку).
  * Версия калибровки прошивки ЭБУ (Calibration ID).
  * Контрольная сумма прошивки (CVN).
  * Название блока управления (ECU Name).
  * Версия чипа ELM327 и тип протокола связи (`AT DP`).
* **Интерактивная консоль**: отправка любых ручных AT и OBD команд.
* **Кнопки быстрого вызова**: `AT Z`, `AT RV`, `09 02`, `03`, `04`, `01 00`, `AT I`, `AT DP`.

### 5. Подключение и транспортный уровень (Connection Layer)
* **Bluetooth Classic SPP**: подключение к адаптерам через стандартный UUID `00001101-0000-1000-8000-00805F9B34FB`.
* **Wi-Fi TCP Socket**: прямое подключение к Wi-Fi адаптерам по IP и порту (по умолчанию `192.168.0.10:35000`).
* **Служба `ObdConnectionService`**: Foreground Service с типом `connectedDevice` для предотвращения обрыва связи в фоне на Android 14/15.

## Архитектура и стек технологий

* **Язык**: Kotlin 2.0
* **UI**: Jetpack Compose + Material 3 (Темная автомобильная тема)
* **Архитектура**: Clean Architecture / MVVM (`ObdViewModel` + `StateFlow`)
* **Асинхронность**: Kotlin Coroutines (опрос датчиков в `Dispatchers.IO`)
* **Навигация**: Jetpack Navigation Compose
* **Целевая платформа**: Android 15 (API 35), минимальная версия: Android 8.0 (API 26).

## Как открыть и собрать проект

1. Откройте **Android Studio** (версия Ladybug / Koala или новее).
2. Выберите **File -> Open...** и укажите папку:
   `c:\elm\ObdMaster`
3. Дождитесь автоматической синхронизации Gradle.
4. Подключите смартфон с Android 15 (или запустите эмулятор с Android 15) и нажмите **Run (Shift + F10)**.
